Employee Analytics Dashboard
Project Overview
I created an Employee Analytics Dashboard using Microsoft Power BI to help an HR Manager understand employee information through clear visualizations.
Dataset
This project uses a fictional sample HR dataset containing 30 employee records. It includes department, gender, monthly salary, attendance percentage, and performance rating.
Dashboard Features
- Total number of employees
- Average monthly salary
- Average employee performance
- Average attendance percentage
- Employee distribution by gender
- Employee distribution by department
- Interactive Gender and Department filters
Design Decisions
I used KPI cards to highlight important workforce measures. I selected a donut chart to show gender distribution and a bar chart to compare employee counts across departments. I included filters so users can explore the information by gender and department.
Intended Audience
The dashboard is designed for an HR Manager who wants a quick overview of workforce information.
Limitations
The dataset is fictional and contains only 30 records. All employees are marked Active. The findings should not be treated as actual company workforce results.
